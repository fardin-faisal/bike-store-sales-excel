# Bike Store Sales Dashboard

An Excel sales analytics dashboard built with PivotTables, PivotCharts, and dynamic slicers to evaluate customer purchasing behavior, demographic trends, and income impacts on bike sales.

![Dashboard](images/Bike%20Buyer%20Demographics%20and%20Purchase%20Behavior%20Dashboard.png)

## Questions answered
- How does average income differ between customers who bought a bike vs. those who did not, across genders?


- How does commute distance impact customer bike purchase decisions?


- Which age bracket (Adolescent, Middle Age, Senior) has the highest bike purchase rate?


- What is the relationship between marital status, education level, and bike sales volume?


- How do region, occupation, and homeownership influence customer purchasing habits?


## How it works
- Source data contains customer demographic metrics (Income, Commute Distance, Age Bracket, Marital Status, Education, Region).


- Data cleaned and transformed using Excel nested logical formulas and custom age grouping pipelines.


- Analysis powered by interactive PivotTables linked directly to dynamic charts.


- Slicers for Marital Status, Education, and Region allow real-time filtering across all dashboard charts.


## Tools
Microsoft Excel: PivotTables, PivotCharts, slicers, logical formulas, data transformation, dashboard design.
